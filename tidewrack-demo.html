Tidewrack

Sorts what washes up. Filter by tag, search, sort, and switch layouts. This page runs the real module template, stylesheet, and script with sample articles.

Masonry reads across the rows, like Grid: newest top-left, the next one beside it. Cards keep their natural heights and tuck up under the shorter ones. Without JavaScript it falls back to plain columns, which read down each column.

Search box: Esc clears it. Extras: type fishie, claude or kokido anywhere outside the search box. On touch, long-press Clear filters.
